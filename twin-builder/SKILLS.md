# Agent Kernel Skill Catalog

The 23 skills below are the canonical catalog the Twin Builder maps interview material against. Skills are intentionally broad — each one is a folder of patterns, prompts, and references that a deployed twin loads as it works.

| Skill | Purpose |
| --- | --- |
| `decision-frameworks` | Document recurring decision patterns and tradeoffs |
| `domain-expertise` | Deep knowledge in a specific industry or function |
| `communication-style` | Tone, brevity, formality, structure preferences |
| `stakeholder-mapping` | Who matters, what they care about, how they prefer to be engaged |
| `estimation-and-scoping` | Sizing work, surfacing risks, identifying unknowns |
| `code-review` | Reviewing code with the principal's standards |
| `incident-response` | Triage, communication, post-mortem authoring |
| `hiring-and-interviewing` | Screening, evaluating, calibrating candidates |
| `vendor-evaluation` | Comparing tools, contracts, partnerships |
| `roadmap-planning` | Quarter and year planning, sequencing bets |
| `executive-reporting` | Board updates, exec summaries, narrative reporting |
| `negotiation` | Commercial, partnership, and internal negotiations |
| `coaching-and-feedback` | 1:1s, growth conversations, performance feedback |
| `writing-and-editing` | Drafting docs, memos, posts in the principal's voice |
| `research-and-synthesis` | Pulling together findings, distilling into briefs |
| `conative-operating-system` | Translating Kolbe-style action profiles into twin behavior, tools, guardrails, and evaluation tests |
| `meeting-facilitation` | Designing and running productive meetings |
| `data-interpretation` | Reading dashboards, asking the right second question |
| `guardrails-and-ethics` | What never to do; what always to escalate |
| `knowledge-curation` | Maintaining the principal's reference library |
| `delegation-and-handoffs` | Crisp handoffs, RACI, follow-through |
| `first-principles-thinking` | Breaking arguments down to basics before deciding |
| `personal-operating-system` | Calendar, focus, energy management patterns |

A typical twin selects 4-8 of these. The selection is recorded in `agent-spec.yaml` with a one-sentence rationale per skill, grounded in the interview transcript.
