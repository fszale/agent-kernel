# Conative Operating System Template

## How to Use

Use this template to turn a principal's conative profile into durable digital-twin behavior. Fill it from a Kolbe-style report, interview transcript, working-style notes, or manager observations. Keep the final artifact close enough to paste into `agent-spec.yaml`, `identity.md`, `guardrails.md`, and evaluation tests.
